🚀 Proyectos destacados

🎙️ AcoustiMap

Mapeo colaborativo de contaminación acústica urbana

AcoustiMap es una aplicación web que permite utilizar un dispositivo como un sensor acústico ciudadano para registrar niveles de ruido ambiental y visualizar las mediciones sobre un mapa.

El proyecto busca facilitar la identificación de zonas con altos niveles de contaminación acústica mediante mediciones colaborativas y geolocalizadas.

⚙️ Tecnologías

JavaScript · HTML5 · CSS3 · Web Audio API · Leaflet · OpenStreetMap · Supabase · PostgreSQL · GitHub Pages

✨ Funcionalidades

🎤 Medición de ruido mediante el micrófono del dispositivo.

📊 Procesamiento de intensidad acústica en tiempo real.

🗺️ Visualización geográfica de las mediciones.

📍 Uso de geolocalización.

🗄️ Almacenamiento de información con Supabase y PostgreSQL.

🔐 Enfoque de privacidad en las mediciones.

📱 Interfaz adaptable a dispositivos móviles.
