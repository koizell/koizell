# 🚀 Proyectos destacados

## 🎙️ AcoustiMap

### Mapeo colaborativo de contaminación acústica urbana

Aplicación web que convierte un dispositivo en un **sensor acústico ciudadano**, permitiendo medir niveles de ruido ambiental, compartirlos de forma anónima y visualizar zonas de contaminación acústica sobre un mapa.

<div align="center">

[![AcoustiMap](https://github-readme-stats.vercel.app/api/pin/?username=koizell\&repo=acoustimap\&theme=dark\&hide_border=true\&bg_color=0D1117\&title_color=00D4FF\&icon_color=00D4FF)](https://github.com/koizell/acoustimap)

</div>

### ⚙️ Tecnologías

`JavaScript` · `HTML5` · `CSS3` · `Web Audio API` · `Leaflet` · `OpenStreetMap` · `Supabase` · `PostgreSQL` · `GitHub Pages`

### ✨ Funcionalidades

* 🎤 Medición de ruido mediante el micrófono del dispositivo.
* 📊 Procesamiento de intensidad acústica en tiempo real.
* 🗺️ Visualización geográfica de las mediciones.
* 📍 Geolocalización con protección de la ubicación exacta.
* 🗄️ Almacenamiento de mediciones mediante Supabase y PostgreSQL.
* 🔐 Privacidad por diseño.
* 📱 Interfaz adaptable a dispositivos móviles.
* 🌐 Aplicación desplegada mediante GitHub Pages.
